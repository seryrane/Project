# 대화형 챗봇 — 표준 질의 설계 (HMG 통합 관리자 포털)

> 자매 프로젝트(Acrofuture Portal)의 대화형 통계 챗봇 설계를 이 포털로 이식했다.
> 그쪽 규칙은 **실제로 겪은 사고**에서 나온 것이라 근거째 가져온다.
> 상위 규약: `docs/화면_공통규칙.md` (표시 영역 1절 · 알림 2절 · 로딩 3절 · 다국어 4절).

**이 문서는 챗봇이 무엇을 묻고 어떻게 답하는지의 정본이다.** 질의를 늘리거나 답의 칸을
바꿀 때는 코드보다 여기를 먼저 고친다.

---

## 0. 뼈대 — 숫자는 코드가 세고, 말만 붙인다

```
물어본 말
   │
   ▼  ① 질의 명세로 바꾼다 (ask.parse)        무엇을 · 언제
   ▼  ② 숫자는 서버 코드가 센다 (ask 서비스)   그 사람 권한 범위 안에서
   ▼  ③ 답을 정해진 칸에 채운다 (ask.report)
   └─▶ 무엇으로 알아들었나 · 한 줄 결론 · 근거 · 특이사항 · 다음에 + [그 화면 열기]
```

⚠ **AI 에게 숫자를 만들게 하지 않는다.** 자연어를 알아듣는 일과 숫자를 세는 일은 다르다.
세는 일까지 맡기면 틀린 숫자가 그대로 보고가 되고, **틀렸다는 사실조차 아무도 모른다.**
(이 저장소도 이미 겪었다 — 요구사항 파싱에서 조용히 빠진 항목이 있었다.)

⚠ **답의 칸을 먼저 정한다.** 나중에 AI 서술을 얹더라도 이 칸만 채우게 한다. 자유 문장으로
받으면 AI 가 숫자를 지어내고, 그 숫자는 차트와 어긋난다.

⚠ **표준 질의 밖으로 나가지 않는다.** 자유 입력은 받되 **답할 수 있는 것만** 답한다.
열어 둔 입력창이 무엇이든 물어도 되는 것처럼 보이면, 답 못 할 질문을 하고 이상한 답을
받은 사람은 **그 뒤로 이 기능을 안 쓴다.**

---

## 1. 자리 — 우측 패널 한 벌

**어느 화면에서나 같은 패널 하나를 연다**(GNB 💬 · 커맨드 팔레트 · `?` 도움말과 같은 층).

- 특정 화면 안에 두면 → 그 화면 권한이 없는 사람은 챗봇 자체를 못 쓴다.
  "내 할 일 몇 개?"를 묻는 일반 사용자가 KPI 권한을 가져야 하는 셈이 된다.
- 화면마다 두면 → 같은 것을 여러 벌 만들게 된다(규약 1절 이중 금지).
- **RIGHT(우측 패널)인 이유**: 물어보는 동안 **본문을 보면서** 답을 맞춰 본다.
  답에 [그 화면 열기]가 붙는데 본문을 덮으면 그 길이 뜻을 잃는다.
- 좁은 화면에서는 규약 §8 대로 **전체를 덮는 시트**로 열린다.

## 2. 사용자 유형별 질의 카테고리

**카테고리는 권한의 파생물이다** — 화면이 유형을 다시 판단하지 않는다(RBAC 설계노트 2절).
서버가 그 사람의 역할 매트릭스로 걸러서 준다.

| 유형 | 무엇을 묻나 | 필요한 권한(메뉴·조회) |
|---|---|---|
| **모든 사용자** | 내 할 일 · 기능이 어디 있나 | 없음 |
| **사양 담당(Editor 이상)** | 사양서 현황 · 승인 대기 | `사양서 관리` · `승인 관리` |
| **품질·검증 담당** | 검증 처리량 · 오류 유형 | `검증엔진` |
| **KPI 담당·임원** | 지표 승인 현황 · 센터 KPI 추이 | `통계 & 분석` |

⚠ **권한은 진입점이 아니라 질의마다 건다.** 엔드포인트 하나에 걸면 챗봇이 임원 전용이 된다.

**답변에는 늘 가는 길이 붙는다.** 말로만 "검증 결과에서 보세요"라고 하면 사람이 그 메뉴를
찾아야 한다 — 메뉴 키를 함께 주면 화면이 버튼 하나로 만든다(권한이 없으면 안 그린다).

## 3. 지금 답하는 것

| 지표 | 무엇을 세나 | 모양 | 필요 권한 |
|---|---|---|---|
| `spec.status` | 상태별 사양서 수 | 막대 | 사양서 관리 |
| `approval.pending` | 결재를 기다리는 건 | 목록 | 승인 관리 |
| `validation.volume` | 월별 검증 처리량 | 막대 | 검증엔진 |
| `validation.error` | 오류 유형별 건수 | 막대 | 검증엔진 |
| `kpi.status` | 지표 승인/검토 현황 | 목록 | 통계 & 분석 |
| `my.todo` | 내가 할 일 | 목록 | 없음 |
| `howto` | 그 기능이 어느 메뉴에 있나 | 목록 | 없음 |

**기간 해석**: 상반기·하반기 · N분기 · 최근 N개월 · YYYY년 · 작년/올해 · 이번 달·지난달·다음 달.
못 알아들으면 **그렇다고 적고** 기본값으로 답한다 — 조용히 답하면 사람은 그것을 자기 질문의
답으로 읽는다.

## 4. 답의 칸 (바꾸지 않는다)

```
무엇으로 알아들었나   2026년 1월 ~ 6월 검증 처리량      ← 질의 명세가 만든다
못 알아들은 것        ※ 기간을 못 찾아 최근 12개월로 봤습니다
숫자                  막대 또는 목록
한 줄 결론            합계 3.8M건 · 월 평균 634K건
근거                  가장 많은 달 · 앞뒤 절반 비교
특이사항              튀는 달 · 빈 달 (없으면 적지 않는다)
다음에                무엇을 하면 되나 + [그 화면 열기]
이어 물을 것          표준 질의 안에서 다음 질문을 권한다
```

- **할 말이 없으면 빈 칸으로 둔다.** "특이사항 없음"을 길게 쓰면 다음부터 아무도 안 읽는다.
- **0 을 평온함으로 읽지 않는다** — 값이 없으면 "자료가 아직 안 채워졌다"고 말한다.

---

## 5. 다국어

챗봇의 답은 **서버가 만든 문장**이라 다국어가 화면 사전만으로 해결되지 않는다.
그래서 **요청에 `locale` 을 실어 보내고 서버가 그 언어로 문장을 만든다**(규약 §4-2 의
"서버는 재료를 준다"를 못 지키는 예외 — 문장 자체가 계산 결과라서). 지키는 것:

- 문장은 **템플릿 + 값**으로 만든다. 통째 문자열을 언어마다 손으로 적지 않는다.
- **데이터 값은 번역하지 않는다** — 사양서 이름·사람 이름·상태값은 원문 그대로.
- 표준 질의 문장도 언어별로 함께 준다(카탈로그가 언어를 안다).

## 6. 다음에 할 것

| 질의 | 필요한 재료 | 있나 |
|---|---|---|
| 사양서·승인·검증 실측 | 서버에 실제 CRUD | **없다** — 지금은 시드(프런트 목데이터와 같은 값)를 센다 |
| 센터 KPI 추이(임베딩 포함) | Tableau 지표 API | 없다 — 등록부만 있다 |
| AI 서술 얹기 | LLM 호출 통로 | 없다 — **얹더라도 같은 칸만 채운다**(0절) |
| 가이드 본문 연결 | 사용자 가이드 섹션 검색 | 있다(`data/community.ts`) — 연결만 하면 된다 |

⚠ **새 기능을 만들면 표준 질의에 한 줄을 더한다.** 여기 적힌 것이 사람이 아는 전부가 된다 —
기능이 늘어도 이 줄이 그대로면 **새 기능은 아무도 물어보지 않는다.**

## 7. 구현 (2026-08-06)

| 무엇 | 어디 |
|---|---|
| 질의 파싱·기간 해석·답 조립 | `backend-python/app/ask.py` — **순수 함수만**(DB 를 모른다, 테스트가 서버 없이 돈다) |
| 카탈로그·질의 API | `backend-python/app/api/ask.py` — `GET /api/ask/catalog` · `POST /api/ask` |
| 셀 재료(시드) | `app/seeds.py` 의 `CHATBOT_*` — 프런트 목데이터와 같은 값. **본개발에서 실제 API 로 교체** |
| 화면 | `frontend/src/components/portal/AskPanel.tsx` — Drawer(RIGHT). 진입은 GNB 💬 와 ⌘K 팔레트 |
| 테스트 | `backend-python/tests/test_ask.py` 13건 + 모바일 스모크 1건 |

**권한 없는 질의는 403 이 아니라 200 으로 답한다** — 답의 칸을 채워 "이 질문은 …권한이 있어야
답할 수 있습니다"로. 에러로 내보내면 사람은 고장으로 읽는다.

**카테고리 노출은 OR** — 그 카테고리의 메뉴 중 **하나라도** 조회 권한이 있으면 보인다.
안에서 못 답하는 질문을 고르면 위 규칙대로 정중히 물러난다. 카테고리째 감추면 "물어볼 수
있는 것이 무엇인지"조차 알 수 없다.
