# 오프라인 전달본 — 파일 하나로 보는 시안

리뷰어에게 **주소(URL) 대신 파일을 건네야 할 때** 쓴다. 받는 쪽은 더블클릭만 하면 되고,
서버·인터넷·설치가 모두 필요 없다.

```
npm run build:offline        # frontend/ 에서
→ frontend/dist-offline/HMG_포털_시안.html   (약 4.8MB, 파일 하나)
```

## 무엇이 다른가

```
평소(터널 시연)                        오프라인 전달본
────────────────────────────────      ────────────────────────────────
vite.config.ts                        vite.config.offline.ts
TanStack Start(서버 렌더)             순수 브라우저 앱
dist/server/server.js 를 띄운다        띄울 것이 없다 — 파일이 곧 화면
/dashboard (History API)              #/dashboard (해시)
JS·CSS·글꼴이 파일 200개               전부 한 파일 안에 (data URI)
LNB 전 메뉴 20개                       핵심 8개 (아래)
/api 로 백엔드에 묻는다                 묻지 않는다 — 전부 mock
```

핵심 8개: 대시보드 · 센터 KPI 대시보드 · 인포 IVI KPI · 지표 관리 ·
사양서 관리 · 상태 보드 · 승인 관리 · 배포 관리 (2026-09-01 사용자 선택).

## 어디를 고치면 무엇이 바뀌나

- **보일 메뉴** → `frontend/src/lib/offline.ts` 의 `CORE_PATHS` 한 곳.
  LNB·커맨드 팔레트·대시보드 위젯·알림 벨이 **모두 이 목록 하나를 본다** —
  메뉴만 걷으면 "갈 곳 없는 링크"가 남는다(규약 §17). 그래서 관문이 하나다.
- **전달본 전용 동작** → 같은 파일의 `OFFLINE` 플래그.
  로그인(서버 없이 통과) · Tableau 임베딩(대신 이유를 적은 자리) · API 호출(아예 안 함).
  ⚠ 평소 빌드에서는 `import.meta.env.VITE_OFFLINE` 이 없어 **전부 죽은 가지**다.

## 밟았던 함정 (2026-09-01, 전부 실측)

1. **`dist/` 를 그대로 압축해 보내면 백지다.** 그 빌드는 서버(server.js)를 전제하고,
   `dist/client` 엔 index.html 조차 없다.
2. **`file://` 은 모듈 스크립트를 막는다**(로컬 파일은 출처가 없다 → 교차 출처로 본다).
   그래서 `format: 'iife'` 로 뽑아 `<script>` 로 **본문째** 넣는다. 글꼴도 같은 이유로
   바깥에 두면 못 읽어 온다 → `assetsInlineLimit` 을 키워 data URI 로 넣는다.
3. **Tailwind 가 `src/` 를 안 훑는다.** 빌드 뿌리가 `offline/` 이라 자동 탐지가 거기서
   멈춘다. 토큰·글꼴은 나오는데 `flex`·`grid` 가 **0개**로 나와, 글자만 세로로 흐르는
   화면이 된다. `offline/styles.offline.css` 의 `@source '../src'` 가 그 한 줄이다.
4. **치환은 함수로.** 포장 스크립트에서 `html.replace('</head>', 큰문자열)` 로 넣으면
   JS 가 본문 속 `$&`·`$'` 를 치환 지시로 읽어 문서를 통째로 되붙인다 —
   5MB 로 나와야 할 파일이 **131MB** 가 됐다.
5. **CSS 가 두 개 나온다.** `__root.tsx` 의 `styles.css?url`(서버 렌더용 링크)이 쓰지 않는
   한 벌을 남긴다. 포장 스크립트는 이름이 아니라 **유틸리티가 든 쪽**을 고른다.

## 확인 방법

브라우저 확장은 `file://` 을 못 연다 — Playwright 로 연다.

```js
const url = pathToFileURL('.../HMG_포털_시안.html').href
await page.goto(`${url}#/dashboard`)   // 해시를 붙여 화면을 지정한다
```
