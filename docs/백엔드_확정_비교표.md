## 1. 한 줄 결론
**추천: FastAPI(`backend-python/`) 로 확정**하고 Spring Boot 스캐폴드는 저장소에서 내린다(태그로 보존).
고객 정황 4가지가 모두 Python 쪽이고, 잰 값(API 범위 · 시험 수 · CI 시간 · 이 PC 빌드 가능 여부)도 모두 FastAPI 가 앞선다.
Spring 이 이기는 경우는 하나 — 고객이 «WAS = Java 표준» 을 요구할 때. 이건 회의 #69 에서 확인할 질문으로 남긴다.

## 5. 추천 안
**가: FastAPI 로 확정(추천)** — 정황 4개 일치 · 기능 · 시험 · CI 모두 앞섬 · 이 PC 에서 바로 빌드됨. Kafka · 보안은 구성 작업으로 메운다.
나: Spring Boot 로 확정 — 고객이 Java WAS 를 표준으로 못박을 때만. 12 경로 · 21 시험 포팅과 개발 PC 경로 우회가 먼저 필요.
다: 결정 보류(지금처럼 두 벌) — 업무 로직을 계속 못 넣는다. 비추천.

회의 #69 에서 고객에게 확인할 것 하나: «WAS Python Framework» 표기가 표준 요구인지, Kafka 연계가 1차 범위인지.

## 7. `frontend/src/routeTree.gen.ts` 판정
- 생성 파일이다(CLAUDE.md «never edit it by hand»).
- 작업 트리의 «M» 은 **내용 변경이 아니었다** — 파일의 blob 해시가 HEAD 와 같다(`a76f01b`, md5 동일). `core.autocrlf=true` 인데 파일이 LF 로 쓰여 색인 stat 만 어긋난 상태. `git add` 로 색인만 새로 고쳐 깨끗해졌다(커밋할 내용 없음 · 되돌릴 내용 없음).
- 재생성 비교(임시 worktree):
  - `npm run build`(Vite TanStack Start 플러그인)가 만드는 파일 = 커밋된 파일과 바이트까지 같음.
  - **`npm run generate-routes`(`tsr generate` CLI)는 다르다** — 끝의 `declare module '@tanstack/react-start' { interface Register { ssr: true; router: … } }` 9줄을 빠뜨린다. CLAUDE.md 가 라우트 추가 뒤 이 스크립트를 쓰라고 안내하므로, 그대로 따르면 Start 의 타입 등록이 빠진 파일을 커밋하게 된다 → 차주 목표 표 마지막 줄.

## 재는 법
- 파일 · 줄: `git ls-files backend | wc -l`, 시드 · 생성물 제외 `*.java` · `*.py` 줄 합.

- 로컬: 저장소 밖 ASCII 경로 사본(`C:\gh-minseo-tmp`)에서 PowerShell `Measure-Command`. CPU 8 논리코어 · 측정 중 부하 100%.
